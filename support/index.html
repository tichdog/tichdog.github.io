О приложении

Todo Calendar — приложение для личных задач: списки и подзадачи, календарь (год, месяц, неделя, день), канбан-доски, заметки с шифрованием, ежедневные дела, трекер привычек и ежегодные даты. Работает офлайн, синхронизируется через Google Drive пользователя.

Установка

Android

  1. Скачайте APK со страницы последнего релиза.
  2. Откройте файл. Android спросит разрешение на установку из этого источника — разрешите его только для браузера или проводника, из которого ставите.
  3. После установки разрешение можно отозвать в настройках.

Если приложение уже установлено, новая сборка обновится поверх, данные сохранятся. Удаление приложения удаляет локальные данные — заранее сделайте экспорт.

Windows

  1. Скачайте архив ToDo_Windows_x64.zip и распакуйте его в постоянную папку.
  2. Запустите ToDo.exe. Установщик не требуется.
  3. Для напоминаний приложение должно быть запущено. Быструю заметку можно добавить в автозапуск в настройках.

Linux

  1. Скачайте ToDo_Linux_x64.tar.gz и распакуйте архив.
  2. Запустите файл ./ToDo из папки сборки.
  3. Если не хватает системных библиотек, установите их средствами дистрибутива (GTK 3, libsecret).

Синхронизация

Синхронизация включается после входа через Google. Приложение хранит снапшот в собственной приватной папке в Google Drive (appDataFolder), поэтому файл не виден в «Моём диске» — это ожидаемое поведение, а не ошибка.

  • Изменения на двух устройствах сливаются по времени последней правки: более свежая версия задачи побеждает.
  • Если Drive недоступен, приложение продолжает работать локально, а очередь синхронизации отправится позже.
  • В гостевом режиме синхронизации нет: данные остаются только на устройстве.
  • Чтобы подтянуть изменения с другого устройства, откройте приложение или нажмите «Синхронизировать» в меню аккаунта.

Напоминания

  • Android: уведомления планируются системой и переживают перезагрузку. Нужны разрешения на уведомления и точные будильники; на устройствах Xiaomi, Huawei и Samsung дополнительно отключите оптимизацию батареи для приложения.
  • Windows и Linux: напоминания работают на таймерах внутри запущенного приложения. Если окно закрыто, уведомление не придёт.
  • Проверить доступ можно тестовым уведомлением в настройках напоминаний.

Удаление данных

Разработчик не хранит ваши данные, поэтому удаление выполняется на устройстве и в вашем аккаунте Google.

Только локальные данные (если Drive недоступен) Тот же пункт: приложение предложит очистку только на этом устройстве и предупредит, что облачная копия останется
Облачная копия без доступа к приложению Отозвать доступ приложения к аккаунту на myaccount.google.com/permissions — файлы в appDataFolder удаляются вместе с доступом

Перед удалением. Если данные ещё могут понадобиться, сохраните резервную копию: «Аккаунт → Данные → Экспорт». Файл JSON можно импортировать обратно в приложение.

Частые вопросы

Приложение не видит аккаунт Google при входе

Проверьте интернет и системное время: неверные часы ломают OAuth. На Android убедитесь, что в системе добавлен хотя бы один Google-аккаунт. Если вход всё равно не проходит, приложение продолжит работать в гостевом режиме — данные не потеряются.

После обновления пропали задачи

Проверьте вкладку «Корзина» и фильтры: возможно, включён тег или поиск. Если данные были синхронизированы, нажмите «Синхронизировать» — снапшот в Drive содержит последнюю версию.

Забыл пароль от скрытых заметок

Восстановление невозможно: ключ шифрования не хранится ни на сервере, ни в облаке в открытом виде. В настройках безопасности заметок можно сбросить защиту — скрытые заметки будут удалены, остальные данные останутся.

Синхронизация зависла или показывает ошибку

Проверьте интернет и доступ к Drive, затем повторите синхронизацию. Если ошибка повторяется, посмотрите локальный файл crash_log.txt рядом с данными приложения и приложите его к сообщению об ошибке.

Как перенести данные на новое устройство?

Войдите в тот же Google-аккаунт и включите синхронизацию — задачи, заметки, доски и привычки подтянутся из Drive. Альтернатива без сети — экспорт JSON на старом устройстве и импорт на новом.

Приложение замедляет телефон или садится батарея

Активно используется только при открытом приложении; в фоне работают лишь запланированные уведомления. Если расход остаётся высоким, отключите автосинхронизацию по расписанию в настройках.

Где код приложения?

Исходный код приватный, но сборки и список изменений открыты в репозитории релизов.

Installation

Android

  1. Download the APK from the latest release page.
  2. Open the file. Android will ask for permission to install from this source — allow it only for the browser or file manager you are using.
  3. The permission can be revoked in settings afterwards.

If the app is already installed, the new build updates in place and your data is kept. Uninstalling removes local data — export a backup first.

Windows

  1. Download ToDo_Windows_x64.zip and unpack it into a permanent folder.
  2. Run ToDo.exe. No installer is required.
  3. Reminders need the app to be running. Quick note can be added to autostart in settings.

Linux

  1. Download ToDo_Linux_x64.tar.gz and unpack the archive.
  2. Run ./ToDo from the build folder.
  3. If system libraries are missing, install them through your distribution (GTK 3, libsecret).

Sync

Sync turns on after signing in with Google. The app keeps its snapshot in its own private Google Drive folder (appDataFolder), so the file is not visible in “My Drive” — that is expected, not a bug.

  • Changes from two devices are merged by last-modified time: the newer version of a task wins.
  • If Drive is unreachable, the app keeps working locally and the sync queue is sent later.
  • Guest mode has no sync: data stays on the device only.
  • To pull changes from another device, open the app or tap “Sync” in the account menu.

Reminders

  • Android: notifications are scheduled by the system and survive a reboot. Notification and exact-alarm permissions are required; on Xiaomi, Huawei and Samsung devices also disable battery optimisation for the app.
  • Windows and Linux: reminders are timers inside the running app. If the window is closed, the notification will not arrive.
  • A test notification in reminder settings verifies the permission.

Data deletion

The developer does not store your data, so deletion happens on your device and in your Google account.

What to deleteHow
All app data, including the Google Drive copy Account → Data → Delete all data → confirm in the dialog and by typing the word
Local data only (if Drive is unreachable) Same item: the app offers a device-only wipe and warns that the cloud copy remains
Cloud copy without the app Revoke the app's access at myaccount.google.com/permissions — files in appDataFolder are deleted with the access
A single task Delete to trash, then “Empty trash”
Hidden notes Account → Notes security → reset protection (removes access to encrypted notes)

Before deleting. If you may need the data later, export a backup: Account → Data → Export. The JSON file can be imported back into the app.

FAQ

Google sign-in does not see my account

Check the connection and the system clock: a wrong time breaks OAuth. On Android make sure at least one Google account is added to the system. If sign-in still fails, the app keeps working in guest mode and your data is safe.

Tasks disappeared after an update

Check the trash tab and the filters: a tag or a search may be active. If the data was synced, tap “Sync” — the Drive snapshot holds the latest version.

I forgot the hidden notes password

Recovery is impossible: the encryption key is stored neither on a server nor in the cloud in readable form. Notes security settings allow resetting the protection — hidden notes are removed, the rest of the data stays.

Sync hangs or reports an error

Check the connection and Drive access, then retry. If the error repeats, look at the local crash_log.txt next to the app data and attach it to your report.

How do I move data to a new device?

Sign in to the same Google account and enable sync — tasks, notes, boards and habits arrive from Drive. An offline alternative is JSON export on the old device and import on the new one.

The app drains my battery

Work happens only while the app is open; in the background only scheduled notifications run. If usage stays high, disable scheduled auto-sync in settings.

Where is the source code?

The source is private, but builds and changelogs are public in the releases repository.
